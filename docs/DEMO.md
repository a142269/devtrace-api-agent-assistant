# DevTrace 5 分钟演示脚本

> 目标：让评审/面试官在 5 分钟内看到“计划 → 工具 → 证据 → 记忆 → 队列 → 审计”的闭环。
> 不要把 `.env`、密码、Key 投屏；演示账号口令从本地凭据文件读取，不写进任何文档。

## 0. 启动（1 分钟）

前置：Docker Desktop 可用，仓库根目录已有本地 `.env`（由 `.env.example` 复制并填值，不提交）。

```powershell
cd backend
docker compose up -d --build
# API: http://127.0.0.1:8000  前端: http://127.0.0.1:5173
```

如果只讲代码、不起服务：

```powershell
cd backend
python -m pytest -q tests
```

预期：`371 passed`（CI 3.12 上会少一个 Windows 专用 skip，属正常）。

## 1. 401 鉴权排障（90 秒）

1. 打开前端，登录演示账号（口令在本地凭据文件，不投屏）。
2. 输入：`请求 req_auth_01 返回 401，帮我排查`。
3. 观察：
   - 计划被服务端批准，工具顺序可见；
   - 依次出现文档检索、请求记录、密钥权限；
   - 证据区区分“支持/否定/仅观察”，答复带来源；
   - 不展示模型内部推理。
4. 口播：**“参数不是模型随便填的：请求编号从用户输入抽取，密钥前缀来自请求记录，工单必须用户授权。”**

## 2. 429 限流（45 秒）

输入：`请求 req_quota_01 遇到 429，如何处理`。

观察：

- 文档检索/请求记录/限流文档；
- 答复包含退避建议，不把 429 误判成 401；
- 证据来源是本地知识库，不连接真实平台。

## 3. Webhook 组合故障（45 秒）

输入：`Webhook 投递 delivery_combo_01 失败，帮我排查`。

观察：

- 投递记录 + 文档 + 关联请求 + 限流文档；
- 关联请求成功时用排除法，不默认因果；
- 计划状态可能是 `waiting`——这是合法的“等用户补充/继续”终态，不是崩溃。

## 4. 流式队列与记忆（60 秒）

1. 用流式入口发同一条 401 请求；
2. 观察 `started → timeline → complete`，以及 15 秒心跳注释；
3. 打开记忆导出（或调用 `GET /developer/memory/{conversation_id}`）：
   - 工作记忆、摘要、画像、`exported_at`、`workspace`；
   - 再 `DELETE` 清理，确认消息/摘要清空、画像保留（画像要单独 `DELETE /developer/profile`）。
4. 口播：**“流式任务由 Redis 队列 + 独立 worker 执行，API 重启不丢；一次流式请求只扣 1 个限流配额。”**

## 5. 管理员视图（45 秒，可选）

需要本地配置 `DEVTRACE_ADMIN_USERS=demo`（不提交）：

- `GET /developer/audit?limit=20`：登录、chat、工具调用、任务事件；
- `GET /developer/metrics`：队列深度、延迟/死信、worker 心跳；
- `GET /developer/dead-letter`：死信列表；`POST /developer/tasks/{id}/replay` 重放（仅演示）。

口播：**“审计是应用层只追加，不是 WORM；生产要换真正的审计存储。”**

## 6. 故障恢复（可选，30 秒口头讲）

不要现场跑 `kill -9`（需要真实模型/时间）。直接展示：

- `FINAL_REVIEW.md` 里 P12 的 kill 时间线；
- 关键数字：enter running 后 1.22s 被杀 → 租约到期后 3.12s 被幸存 worker 回收 → `attempts 0→1` → 唯一终态、一条审计、锁释放。

## 7. 收尾话术（30 秒）

> “这是一个演示级完整 Agent，不是生产系统。它证明了：受约束规划、工具安全、证据诊断、记忆/队列/审计这些工程件能一起工作，并且有可复核的测试和评测。生产化还缺身份/TLS/WORM/HA，这些我在 README 的限制清单里都写明了。”

## 常见问题

- **计划一直 `waiting`？** 这是合法终态：需要用户补充标识符或发送“继续”，不是错误。
- **没有模型 Key？** 规则模式仍可跑通演示；评测会跳过真实模型部分。
- **端口被占用？** 只改本地 compose 端口，不要改仓库默认值；演示后 `docker compose down`，不要加 `-v`。
- **前端 429？** 流式入口与同步入口共用 30/min/user 配额；等 60 秒或换账号。
